# Numerical TOSA fixtures

These stable TOSA 1.0 FlatBuffers are generated by the private, checked TOSA builders in
`virtio-accel-tosa`'s unit tests. `numerics.rs` couples each artifact to static shapes, inputs,
expected FP32/FP16 values, packed FP8/INT8/INT4 bytes, or exact INT32 accumulators, and comparison
rules. FP8 NaN payloads may be canonicalized; all other packed values compare bit-for-bit. INT4
uses TOSA's low-nibble-first ordering and excludes the reserved `-8` encoding. The INT8 matrix
multiplication fixture uses nonzero zero points so a backend cannot pass by treating storage bytes
as unquantized operands.

Regeneration is explicit and writes only the exact path supplied through
`VIRTIO_ACCEL_TOSA_FIXTURE_OUT`; the ordinary test suite never mutates the source tree. Every
regenerated graph is parsed and semantically validated for its floating-point or integer Level 8K
target and required FP8/INT4 extension before it is admitted to this corpus.
